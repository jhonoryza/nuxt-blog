# AGENTS.md — components/ui/ (shadcn-vue)

## Purpose
shadcn-vue UI components managed by `shadcn-nuxt` module. Standardized design system for the app.

## Ownership
- All components under `components/ui/` — badge, button, card, input, table

## Local Contracts
- **Generated by**: `shadcn-nuxt` module — do not manually create/edit unless customizing
- **Pattern**: Each component has `index.ts` (re-export) + Vue file (`index.vue` or `ComponentName.vue`)
- **Import alias**: `@/components/ui/xxx`
- **Shared util**: `@/lib/utils` for `cn()` function
- **Styling**: Tailwind CSS utility classes + shadcn-vue CSS variables (oklch)
- **Framework**: shadcn-vue + Radix Vue (`radix-vue`)

## Work Guidance
- Prefer existing components before adding new ones
- Customizations allowed but must preserve CSS variable contract
- New shadcn-vue components should be added via `npx shadcn-vue add <component>` or UI
- No app-specific business logic — keep purely presentational

## Verification
Visual inspection in browser; ensure both light and dark modes render correctly.
